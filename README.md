# Tegarg28 Portfolio

## 🚀 Setup

1. Clone or extract this folder.
2. Install dependencies:

```bash
npm install
```

3. Start development server:

```bash
npm run dev
```

## 📦 Built With

- React
- Vite
- Tailwind CSS

## 🧱 Structure

- `Navbar`, `Hero`, `About`, `Skills`, `Portfolio`, `Contact` are modular components in `src/components/`.

## 🔧 Customization

You can edit text, styles, and layout in the respective components.
